# Brand icons

The marks of the tools the build needs, so the panel shows each one as itself instead of a tick.

**Where they come from**: [Simple Icons](https://simpleicons.org), fetched from
`https://cdn.simpleicons.org/<name>/white`. Simple Icons releases its files under **CC0 1.0** (public
domain dedication), which is what makes them safe to keep here.

**Why white**: the window is dark, always. Most brand marks are dark colours - Rust's is black - and a
black logo on a dark panel is not a logo, it is a hole.

**The ones that are not here, and why**: `windows` and `visualstudio` have no freely distributable icon
in that set - they are trademarks Simple Icons does not ship - so those checks keep the plain mark, and
Windows keeps the four panes this project draws itself. `jq` has none either, and it is shown with the
JSON mark, which is the format it works with.

The marks remain the property of their owners and are used here only to name the tools they belong to.
