# docs/examples

Ejemplos que se pueden ejecutar tal cual para probar funciones de PiCode desde fuera del editor.

- `start-pi-session.ps1`: cliente de referencia de la entrada local para otras apps ([`ENTRADA-LOCAL.md`](../ENTRADA-LOCAL.md)). Abre un proyecto, arranca un chat de pi con un encargo y devuelve el identificador de la sesión.
